# 🤖 AI Resume Screening & Recruitment Assistant

An AI-powered recruitment platform that helps recruiters efficiently screen resumes, evaluate candidates, schedule interviews, and manage the hiring process from a single dashboard.

---

## 📌 Project Overview

AI Resume Screening & Recruitment Assistant automates the recruitment workflow by extracting candidate information from resumes, generating ATS compatibility scores, providing AI-generated candidate summaries, scheduling interviews, sending interview emails, and maintaining recruiter notes.

The project demonstrates the integration of modern web development with AI-powered candidate analysis.

---

## 🚀 Features

- 📄 Resume Upload (PDF)
- 🤖 AI Resume Parsing
- 📊 ATS Score Generation
- ✨ AI Candidate Summary
- 👤 Candidate Management Dashboard
- 🔍 Search & Filter Candidates
- 📅 Interview Scheduling
- ✉️ Email Notifications
- 📝 Recruiter Notes
- 📂 Resume Viewer
- 📥 CSV Export
- 🌙 Dark / Light Theme

## ⚙ Installation

### 1. Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Resume-Screening-System.git
```

---

### 2. Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

### 3. Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
OPENROUTER_API_KEY=YOUR_API_KEY

SUPABASE_URL=YOUR_SUPABASE_URL

SUPABASE_KEY=YOUR_SUPABASE_KEY

EMAIL_USER=YOUR_EMAIL

EMAIL_PASS=YOUR_APP_PASSWORD
```
